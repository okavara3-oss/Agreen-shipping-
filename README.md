# قائمة مراجعة تعليمات الشحن — أجرين

واجهة تفاعلية مبنية على تعليمات الشحن المرفقة (WI-7-9-15).

## الملفات
- `index.html`: التطبيق التفاعلي الكامل، ولا يحتاج إلى تثبيت أو بناء.

## تشغيل محلي
افتح `index.html` في متصفح حديث.

## النشر على GitHub Pages
1. أنشئ Repository جديدًا على GitHub.
2. ارفع `index.html` و`README.md` إلى جذر المستودع.
3. افتح **Settings → Pages**.
4. من **Build and deployment** اختر **Deploy from a branch**.
5. اختر الفرع `main` والمجلد `/(root)` ثم اضغط **Save**.
6. بعد اكتمال النشر، افتح رابط GitHub Pages الذي سيظهر في الصفحة.

## ملاحظات
- علامات الإنجاز تُحفظ في `localStorage` على نفس المتصفح والجهاز.
- العلامات لا تتزامن بين الأجهزة أو المتصفحات.
- يمكن تعديل `index.html` مباشرة لإضافة تعليمات أو تعديلها.
- راجع ملف تعليمات الشحن الأصلي عند وجود حالة استثنائية أو تعارض.
